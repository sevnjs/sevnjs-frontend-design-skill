# SevnJS Agent Skill

An AI Agent Skill for building frontends with [SevnJS](https://sevnjs.mgeek.in) — a lightweight vanilla JS utility library.

## Author
- **Maintainer**: Prateek Raj Gautam / prateekrajgautam

## Installation
1. Copy `SKILL.md`, `reference.md`, `examples.md` into your agent's skills directory (e.g., `~/.claude/skills/sevnjs-frontend-design/`).
2. Ensure `SKILL.md` starts with valid YAML frontmatter.
3. Restart the agent — the skill auto-triggers on SevnJS-related prompts.

## Contents
- `SKILL.md` — concise trigger + quick reference
- `reference.md` — full 7-step API curriculum
- `examples.md` — extended design patterns
